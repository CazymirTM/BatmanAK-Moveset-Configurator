# Batman: Arkham Knight - Advanced Moveset Configurator

A modern, high-end desktop utility designed for *Batman: Arkham Knight* modders and players. Easily configure advanced combat movesets, tweak game settings, toggle cheats, spawn enemies, and manage mod files seamlessly through a sleek, premium tabbed interface.

---

## ✨ Features

* **Modern & Premium UI:** Crafted with a clean, dark-themed interface built natively in WPF for a smooth, responsive user experience.
* **Categorized Tab Navigation:** Effortlessly switch between dedicated control centers:
  * **CHEATS:** Quickly toggle powerful gameplay modifiers and adjustments.
  * **ENEMIES:** Manage, tweak, and spawn game encounters.
  * **CONFIGS:** Tweak internal variables and setup custom configurations.
* **Automatic Script Deployment:** Automatically installs the necessary `MovesetInjector` files directly into your game directory to ensure debugging and `Console.txt` functionality work right out of the box.
* **Lightweight & Clean Distribution:** Built with integrated assembly weaving (Costura) to ensure a clutter-free folder structure without messy third-party dependencies.

---

## 🚀 Installation & Setup

1. Download the latest release `.zip` from the [Releases Page](../../releases).
2. Extract the contents to any folder of your choice.
3. Launch `BatmanAK Moveset Configurator.exe`.
4. Point the tool to your *Batman: Arkham Knight* game directory when prompted (or let it auto-detect your installation path).
5. Enjoy customizing your game!

---

## 📦 Requirements
